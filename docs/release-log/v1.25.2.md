# TokenPak v1.25.2 Release Log

## Scope

Proxy cost estimates now use explicit cache-read and cache-write prices from
the resolved model catalog entry. Previously, fixed multipliers overrode those
prices. Explicit zero-valued cache prices are honored. Input and output prices
come from the same resolved entry.

Ordinary Codex launcher upgrades reconcile unchanged legacy skill copies after
installing the canonical copies. Customized copies remain preserved, with
conflicts reported. An installation to a separate export directory keeps its
existing behavior.

## Compatibility and limitations

- The package advances from 1.25.1 to 1.25.2. No public API signature, telemetry
  schema, or TIP version changes. Exact normative docs and registry pins remain.
- Catalog data are unchanged. Cost figures remain rate estimates. Missing
  explicit cache prices retain their existing fallback estimates; unsupported
  long-lived cache-write and long-context price tiers are not added by this fix.
- Historical request costs and populated pricing databases are preserved. This
  release does not retroactively recalculate recorded costs.
- The separately distributed Pro package must declare compatibility with
  OSS 1.25.2 and TIP-1.0. Pro 0.2.0 declares OSS 1.25.1 only. The paired Pro
  0.2.1 artifact is validated and published separately before a paired rollout.
- Production Reroute recommendations still require complete measured inputs
  and eligible empirical priors. Synthetic tests and prepared comprehension
  displays do not supply empirical or human outcome evidence.

## Upgrade and rollback

Upgrade the OSS distribution to `tokenpak==1.25.2`. Existing Pro installations
also need the separately validated compatible Pro artifact. Check the installed
version, package origin and daemon compatibility before treating the pair as
ready. Custom settings and skills remain operator-owned.

Rollback restores the previous verified OSS 1.25.1 and compatible Pro 0.2.0
artifacts, with their existing settings and saved state. Keep backups until the
post-deployment watch completes. No tag is repointed and no published artifact
is replaced. The earlier 1.25.0 tag remains retired without a package release.
