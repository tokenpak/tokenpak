# TokenPak v1.30.1 Release Log

## Scope

This patch release carries the changes merged to the trunk after 1.30.0:

1. **Footer fix.** The Claude Code footer and the Codex pane showed only
   `TokenPak` instead of the session line when the user's locale collates
   regex bracket ranges, for example `en_US.UTF-8` on Linux. The reader's ASCII
   check refused every cached line in that locale. It now runs in byte order
   under any locale. The defect shipped with the footer and is present in
   1.30.0. A regression test runs the real reader under `en_US.UTF-8`.
2. **Personal names removed** from source comments, a schema example and test
   fixtures. The orchestration handoff's human recipient is now registered as
   `operator`; a handoff addressed to the previous name fails as an unknown
   agent.
3. **Documentation pin.** The release metadata's documentation-revision pin
   now names `9d4d425571`, the rewritten commit ID of the same documentation
   content that `a8ce463cfc` held. The documentation repository's history was
   rewritten on 2026-10-01 to remove personal data, so the old ID will stop
   resolving. The runtime validates only the pin's shape; nothing resolves it
   at runtime.
4. **README and documentation home** open with what TokenPak shows for a
   coding-agent session: measured usage, estimated cost, burn and runway.
5. **Release gate.** The leak scan also checks a hashed register of private
   terms, so the guard itself carries no names.

The 1.30.0 release log's publication, convergence and closeout updates are
also part of this cut.

## Upgrade and rollback

Upgrade is a package-only upgrade: no database migration, configuration change
or data backup is required. Rollback is a plain downgrade to the published
1.30.0 package; there is no migration to reverse.

TokenPak Pro 0.5.1 declares OSS 1.26.0 through 1.30.0, and its in-process
compatibility check refuses 1.30.1 (`tokenpak_out_of_range`). Pro installations
stay on 1.30.0 until Pro 0.5.2, which adds 1.30.1, is installed. Pro 0.5.2 is
tested against the exact 1.30.1 release source before it is published.
