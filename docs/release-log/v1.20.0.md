# TokenPak v1.20.0 Release Log

## Scope

This minor release adds a deterministic session trip computer to the default
read surfaces — a one-line and full-block status rendering, a dashboard
section and snapshot field, and a read-only tool shared by both supported
agent clients, all thin adapters over one validated contract and one shared
renderer, with proxy-owned default-session selection. It layers a calibrated
remaining-consumption forecast on top: a dependency-free split-conformal
quantile engine over finished local sessions producing a central 50%
remaining-token range, a one-sided 90% ceiling, an expected-turn range,
measured walk-forward coverage with drift awareness, and a guard-aligned
block probability. Both surfaces carry a non-self-metering restart proof —
value-identical canonical output and byte-identical provider bytes across a
full process restart.

The release also refreshes the model pricing catalog for the current Claude
model generation (Fable 5, Opus 5, Sonnet 5 priced rows and context windows;
a stale Haiku row corrected) and adds a catalog-integrity test suite that
makes this class of staleness CI-detectable without hardcoding a model-name
enumeration.

The release candidate starts from staging commit
`8f0f2cc1751fd7192f187a6ebcdffc8fbfa23b1f`. Validation, publication, and
post-publication stages remain pending.

- **Breaking changes:** none identified.
- **Deprecations:** none introduced.

## User-visible behavior

- The trip computer renders truth-preserving output on every default read
  surface: observed facts print as plain values, estimates are marked, and
  empty/unavailable/error states print as words, never as zeros.
- The calibrated forecast's cold cells render an explicit learning state
  rather than a number; stale or unknown rates leave USD unavailable while
  token ranges stay intact. Measured walk-forward coverage is reported as
  observed, not asserted nominal, and drifting coverage triggers a refit
  rather than a relabel.
- Model pricing for the current Claude model generation (Fable 5, Opus 5,
  Sonnet 5) is now available wherever the proxy consults its canonical
  pricing catalog; a previously mispriced Haiku row is corrected.

## Known issues and limitations

- One legacy per-model pricing display path (a disconnected, hand-maintained
  analytics cost lookup, distinct from the canonical pricing catalog this
  release corrects) does not yet delegate to the shared catalog and can
  still render an incorrect dollar figure for models outside its own
  hardcoded list. It never abstains the way the catalog-backed paths do.
  Tracked as a follow-on, not fixed in this release.
- Calibrated-forecast bands intentionally remain in a learning state for
  cold model/effort cells rather than producing a number before the cell's
  own measured history clears the trust floor.
- Release validation is in progress; any failure and its disposition will be
  retained here rather than overwritten.
