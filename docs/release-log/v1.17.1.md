## Retrospective

- **What dragged:** the API snapshot was regenerated against the integration
  trunk instead of the exact release tree, and the mismatch surfaced only at the
  tag gate — costing a tag re-point (executed cleanly under the release owner's
  named decision, before anything published).
- **What broke or nearly broke:** nothing in production; one benchmark cell
  flaked on runner load and one stale docs-revision pin nearly regressed via a
  wholesale file promotion — both caught before landing.
- **Carry-forward action:** this is the final patch-scale public release; the
  release model consolidates patch work on the integration trunk, with public
  releases at minor/major only, carrying a summarized change list since the
  previous public release.
