# TokenPak v1.17.0 Release Log

## Scope

This minor release adds opt-in, cached update notifications and an explicit lean
companion-output mode while preserving standard native output by default. It also
collects compatibility and reliability repairs for vault injection, CLI startup,
integration consent, uninstall choices, configured paths, preview and configuration
validation, companion labels, installation guidance, Docker custom-config examples,
and fail-closed Pro source-connector gating.
