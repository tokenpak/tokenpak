# TokenPak v1.17.0 Release Log

## Scope

This minor release adds opt-in, cached update notifications and an explicit lean
companion-output mode while preserving standard native output by default. It also
collects compatibility and reliability repairs for vault injection, CLI startup,
integration consent, uninstall choices, configured paths, preview and configuration
validation, companion labels, installation guidance, Docker custom-config examples,
and fail-closed Pro source-connector gating.

## Breaking changes and deprecations

No breaking change or deprecation is intended in this release. Standard companion
output remains the default; lean output remains opt-in. The source-connector repair
fails closed with the documented `Pro tier required` result and does not add network
fallback behavior.

## Known issues

- The checked-in public-API snapshot retains four import-error sentinel records
  for optional framework example modules: AutoGen, CrewAI, LangChain, and
  LlamaIndex. All four records were already present at the release-content
  base; the v1.17.0 snapshot delta remains one addition and zero removals.
- A fully offline install of every optional extra could not include the unavailable
  platform-specific `torch` dependency. Production and TestPyPI online install gates
  remain mandatory and may not inherit that limitation as a pass.
- TestPyPI setup and upload are not complete. The production tag remains blocked until
  the stable `1.17.0` wheel and sdist are uploaded, installed, and validated there.
