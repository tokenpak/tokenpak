# TokenPak v1.17.0 Release Log

## Scope

This minor release adds opt-in, cached update notifications and an explicit lean
companion-output mode while preserving standard native output by default. It also
collects compatibility and reliability repairs for vault injection, CLI startup,
integration consent, uninstall choices, configured paths, preview and configuration
validation, companion labels, installation guidance, and Docker custom-config
examples.

Linked work:

- [Opt-in update notifications](https://github.com/tokenpak/tokenpak-staging/pull/600)
- [Release validation repairs](https://github.com/tokenpak/tokenpak-staging/pull/668)
- [Native companion output by default](https://github.com/tokenpak/tokenpak-staging/pull/670)
- [Release-literal validation repair](https://github.com/tokenpak/tokenpak-staging/pull/672)
- [Docker custom-config coherence repair](https://github.com/tokenpak/tokenpak-staging/pull/673)
