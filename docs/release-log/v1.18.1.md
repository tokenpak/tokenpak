# TokenPak v1.18.1 Release Log

## Scope

This minimum-diff hotfix restores Spend Guard approvals for the documented
Codex integration. It resolves Codex session headers, parses strict approval
intent and TIP directives from OpenAI Responses input, scopes pending and
anti-loop state per session, and prevents identity-less requests from creating
a global approval row.

## Hotfix notes

- **Triggering release:** v1.18.0
- **Hotfix rationale:** A valid Spend Guard approval from Codex repeatedly
  returned HTTP 402 because the parser did not understand Responses input and
  the held request used an empty global session key. This made a documented
  client integration non-functional during active work.
- **Validation shortened:** staging sections outside build/install, startup,
  proxy core, user journey, and regression; upgrade-path and container checks
  only if the final diff remains unrelated to those surfaces.
- **Follow-up by 2026-08-10:** run every shortened check, publish the root-cause
  review, and separately decide whether model context-window metadata needs an
  update.
