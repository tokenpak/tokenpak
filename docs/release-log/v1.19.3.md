# TokenPak v1.19.3 Release Log

## Scope

This patch re-cuts the unpublished v1.19.2 content with one repair: the
public-API snapshot's CrewAI example import-error sentinel is restored to the
value a clean build environment produces. The v1.19.2 preparation regenerated
the snapshot in an environment carrying a stale locally installed integration
package; the release gate's snapshot check therefore failed at the v1.19.2 tag
build, before any distribution, GitHub Release, or index upload was created.

Everything else in this release is the v1.19.2 candidate content unchanged:
Python 3.10 companion launcher compatibility and causal release-to-site
synchronization, as described in the v1.19.2 release log.
