# TokenPak v1.19.1 Release Log

## Scope

This patch fixes interactive Codex clients (0.147 and newer) parking at
startup when routed through the local proxy with a subscription sign-in. The
proxy previously replied to subscription-authenticated `GET /v1/models`
requests with an empty catalog on the assumption that the client carried a
bundled model list; newer clients list models online from their configured
provider and will not proceed past the model-availability step on an empty
reply. The proxy now routes such requests to the subscription backend's model
catalog with the caller's own credential, keeping catalog content and schema
current without maintaining a copy.

The release candidate is the merge of staging PR #729
(`85ddca4ded`, feature head `0291131b94`).
